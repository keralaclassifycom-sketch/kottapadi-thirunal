- **കോട്ടപ്പടി 3D മാപ്പ്** — 21 യൂണിറ്റുകളുടെ അമ്പ്, വള എഴുന്നള്ളിപ്പുകൾ. സമയ സ്ലൈഡർ നീക്കിയാൽ ആ സമയത്ത് ആരൊക്കെ വഴിയിലുണ്ട് എന്ന് കാണാം
- എഴുന്നള്ളിപ്പ് സമയ ചാർട്ട്, ഓരോ യൂണിറ്റിനും 3D കാർഡ്
- **3D പള്ളി**, ദീപാലങ്കാരത്തോടെ (പകൽ/രാത്രി)

## വിവരങ്ങൾ മാറ്റാൻ

**`data.js` എന്ന ഫയലിൽ മാത്രം** മാറ്റം വരുത്തിയാൽ മതി:

| എന്ത് | data.js-ലെ ഭാഗം |
|---|---|
| ദിവസങ്ങൾ, പരിപാടികൾ, സമയം, സ്ഥലം | `DAYS` |
| യൂണിറ്റുകൾ, സമയം, ബാൻഡ്, തുടങ്ങുന്ന സ്ഥലം (`start`), വഴി (`via`) | `UNITS` |
| സ്പോൺസർ ലോഗോ | `SPONSORS` (ലോഗോ ചിത്രം `images/sponsors/` ഫോൾഡറിൽ ഇടുക) |
| കോർഡിനേറ്റർമാർ, ഡിസൈനർമാർ | `TEAM` |
| ഫോട്ടോകൾ | `GALLERY` (`images/` ഫോൾഡറിൽ ഇടുക) |

സമയം 24 മണിക്കൂർ രീതിയിൽ എഴുതുക: `"18:30"`. രാത്രി 12 മണി `"24:00"`.

## GitHub Pages-ൽ ഇടാൻ

1. GitHub-ൽ പുതിയ repository ഉണ്ടാക്കുക (ഉദാ: `kottapadi-thirunal`)
2. ഈ ഫോൾഡറിലെ എല്ലാ ഫയലുകളും upload ചെയ്യുക (`index.html`, `style.css`, `app.js`, `data.js`, `images/`)
3. **Settings → Pages → Branch: `main` / root → Save**
4. ഒന്നു രണ്ടു മിനിറ്റിനുള്ളിൽ ലിങ്ക് കിട്ടും: `https://<username>.github.io/kottapadi-thirunal/`

`_theme-reference/` ഫോൾഡറിൽ ഉള്ളത് പഴയ കലോത്സവം ഡിസൈൻ ആണ്. അത് upload ചെയ്യേണ്ടതില്ല.
