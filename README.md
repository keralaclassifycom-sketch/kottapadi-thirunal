# ⛪ സെൻറ് ലാസേഴ്സ് ചർച്ച്, കോട്ടപ്പടി — തിരുനാൾ 2027

🌐 **ലൈവ് സൈറ്റ്: [kottapadithirunal.in](https://kottapadithirunal.in)**

ചരിത്ര പ്രസിദ്ധമായ കോട്ടപ്പടി തിരുനാളിന്റെ വെബ്സൈറ്റ് (ജനുവരി 1 · 2 · 3 · 4). ഇത് പള്ളിയുടെ ഔദ്യോഗിക സൈറ്റ് അല്ല.

## സൈറ്റിൽ ഉള്ളത്

- **കൗണ്ട്ഡൗൺ, ദിവസം തിരിച്ചുള്ള പരിപാടികൾ** — ഡിസം 25 കൊടിയേറ്റം മുതൽ ജനു 4 വരെ, ഓരോ ദിവസത്തിന്റെയും പ്രധാന പരിപാടികൾ കാർഡിൽ
- **ബാൻഡ് പാട്ട്** — "തിങ്കളേ പൂത്തിങ്കളേ" ഉൾപ്പെടെ, ബാൻഡ് വാദ്യക്കാരുടെ അനിമേഷനോടെ
- **അമിട്ട്** — സ്ക്രീനിൽ തൊട്ടാൽ പള്ളിക്ക് മുകളിൽ അമിട്ട് പൊട്ടും, ശബ്ദത്തോടെ; വെടിക്കെട്ട് ടീമിന്റെ വിവരം
- **തേര് മത്സരം** — 18 ലൈറ്റ് എഫക്ടുകളോടെ ദീപാലങ്കാര തേരുകൾ
- **മേളങ്ങൾ — എവിടെ, എപ്പോൾ?** ബാൻഡ് സെറ്റ്, നാദസ്വരം, ചെണ്ടമേളം; ദിവസം/തരം അനുസരിച്ച് തിരഞ്ഞെടുക്കാം, പേര് തിരയാം
- **ഗാനമേള (തിരുനാൾ സംഗീതരാവ്)** — ഡിസം 31, ജനു 1, ജനു 4; രണ്ട് സ്റ്റേജ്, ഗായകരും ഓർക്കസ്ട്രയും, പാട്ട് മാറ്റാം, ബലൂൺ വിടാം (അമർത്തിപ്പിടിച്ചാൽ കൂടുതൽ)
- **രാപകൽ, അങ്ങാടി** — കടകളും പടക്കവും, ബൈക്കിൽ നിന്ന് ബലൂണുകൾ
- **കോട്ടപ്പടി 3D റൂട്ട് മാപ്പ്** — യൂണിറ്റുകളുടെ അമ്പ്, വള എഴുന്നള്ളിപ്പുകൾ; സമയ സ്ലൈഡർ നീക്കിയാൽ ആ സമയത്ത് ആരൊക്കെ വഴിയിലുണ്ട് എന്ന് കാണാം
- **3D പള്ളി** — ദീപാലങ്കാരത്തോടെ, പകൽ/രാത്രി, തിരിച്ചു നോക്കാം
- **സമൂഹം, ക്ലബ്ബുകൾ, ഗാലറി, ലൊക്കേഷൻ**, സ്പോൺസർമാർ, പരസ്യത്തിന് WhatsApp ബന്ധം
- **ലൈവ്** — ജനു 2, 3 തിയ്യതികളിൽ SL Media വഴി
- **QR കോഡ്** — പോസ്റ്ററിനും (`images/qr-kottapadi-thirunal-poster.png`)
- **സന്ദർശകരുടെ എണ്ണം** — ആകെ, ഇപ്പോൾ ഓൺലൈൻ (Firebase); Google Analytics
- ഓരോ സെക്ഷനും സ്ക്രീനിന്റെ നടുവിൽ വരുമ്പോൾ മാത്രം അതിന്റെ ശബ്ദം; ഒരു സമയം ഒരു ശബ്ദം മാത്രം
- മലയാളം, മൊബൈലിന് പറ്റിയ രൂപം, മുകളിലേക്ക് പോകാൻ ബട്ടൺ

## വിവരങ്ങൾ മാറ്റാൻ

**`data.js` എന്ന ഫയലിൽ മാത്രം** മാറ്റം വരുത്തിയാൽ മതി:

| എന്ത് | data.js-ലെ ഭാഗം |
|---|---|
| ദിവസങ്ങൾ, പരിപാടികൾ, സമയം, സ്ഥലം | `DAYS` |
| യൂണിറ്റുകൾ, സമയം, ബാൻഡ്, തുടങ്ങുന്ന സ്ഥലം (`start`), വഴി (`via`) | `UNITS` |
| സ്പോൺസർ ലോഗോ | `SPONSORS` (ലോഗോ ചിത്രം `images/sponsors/` ഫോൾഡറിൽ ഇടുക) |
| കോർഡിനേറ്റർമാർ, ഡിസൈനർമാർ | `TEAM` |
| ഫോട്ടോകൾ | `GALLERY` (`images/` ഫോൾഡറിൽ ഇടുക) |
| ഗാനമേള ട്രൂപ്പുകൾ, പാട്ടുകൾ | `GANAMELA` |
| ക്ലബ്ബുകൾ | `CLUBS` (ലോഗോ `images/clubs/`) |
| പരസ്യ WhatsApp നമ്പർ | `ADVERTISE` |
| സൈറ്റ് ലിങ്ക് | `FEAST.siteUrl` |

**തിരുകർമ്മ ക്രമവും (നൊവേന, കുർബ്ബാന, കാർമ്മികർ, നിയോഗം, സമർപ്പണം) വികാരിയച്ചന്റെ സന്ദേശവും** `data-liturgy.js`-ൽ ആണ്.
ഇപ്പോൾ അതിൽ 2026-ലെ മാതൃക മാത്രം, അതുകൊണ്ട് `published: false` — സൈറ്റിൽ കാണില്ല.
ലിങ്കിന്റെ അവസാനം `?preview` ചേർത്താൽ മുൻകൂട്ടി കാണാം. 2027-ലെ വിവരങ്ങൾ ചേർത്ത ശേഷം `published: true` ആക്കുക.

സമയം 24 മണിക്കൂർ രീതിയിൽ എഴുതുക: `"18:30"`. രാത്രി 12 മണി `"24:00"`.

## സൈറ്റ് എവിടെ ഓടുന്നു

- GitHub Pages (`main` ബ്രാഞ്ച്, root) — `main`-ലേക്ക് push ചെയ്താൽ ഒന്നു രണ്ടു മിനിറ്റിനുള്ളിൽ ലൈവ് ആകും
- ഡൊമെയിൻ `kottapadithirunal.in` — `CNAME` ഫയൽ; DNS Cloudflare-ൽ (SSL: **Full**)
- പഴയ `github.io` ലിങ്ക് തനിയെ പുതിയ ഡൊമെയിനിലേക്ക് പോകും
- മാറ്റം വരുത്തിയ JS/CSS ഫയലിന്റെ `?v=` നമ്പർ `index.html`-ൽ കൂട്ടുക, എങ്കിലേ ഫോണുകളിൽ പുതിയത് കാണൂ
